Privacy Policy

Effective 26 October 2026

This policy covers the Done the Reading website (this site) and Done the Reading Studio (“the Studio”), a personal tool the channel owner uses to publish videos to the Done the Reading YouTube channel. Contact: clancyrobert420@gmail.com.

Who uses the Studio

The Studio is not a public service. It runs only on the channel owner’s own computer and is used only by the channel owner, signed in with their own Google account, to manage their own YouTube channel. No one else can sign in to it or have their data processed by it.

YouTube API Services

The Studio uses the YouTube API Services. By using the Studio you agree to be bound by the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

What the Studio accesses

After the channel owner signs in with Google and grants permission, the Studio uses these permissions, and only for the purposes listed:

  • Upload videos (youtube.upload): to upload the channel owner’s finished videos, with their title, description, tags, visibility and the altered or synthetic content disclosure.
  • Manage the YouTube account (youtube): to read the channel’s name, set custom thumbnails, and change a published video’s title and thumbnail when the owner chooses a different version.
  • View YouTube Analytics reports (yt-analytics.readonly): to show the owner daily views and watch time for their own videos, so they can compare titles and thumbnails.

The Studio does not read, collect or store data about viewers, subscribers or any other YouTube users. It does not access comments, messages, contacts or any Google service other than YouTube.

TikTok

The Studio can also send finished vertical clips to the channel owner’s own TikTok account using TikTok’s Login Kit and Content Posting API. After the owner signs in with TikTok and grants permission, it uses:

  • Basic profile (user.info.basic): to show which TikTok account is connected.
  • Upload videos (video.upload): to send a clip to the owner’s TikTok inbox as a draft. The owner adds the caption and posts it in the TikTok app themselves.

The Studio doesn’t read anyone else’s TikTok data, followers, comments or messages. The TikTok sign-in token is stored only on the owner’s computer, and TikTok data is never sold or shared. The sign-in passes once through a forwarding page on this site, which hands it straight to the Studio on the owner’s computer and stores nothing. TikTok’s own handling of data is described in the TikTok Privacy Policy. Access can be removed in the TikTok app under Settings and privacy → Security → Manage app permissions, or with Disconnect in the Studio.

Where data is stored

  • The Google and TikTok sign-in tokens and app keys are stored only on the channel owner’s computer, in the Studio’s own folder. They are never uploaded anywhere else.
  • The video ID, which title and thumbnail are live, and a history of changes are stored in a small file in the video’s project folder on that computer.
  • Analytics figures are fetched when the owner asks for them and shown on screen. They aren’t kept after that.

Nothing is sent to any server other than Google’s and TikTok’s own services. No data from the YouTube API Services or TikTok is sold, shared, given to third parties, or used for advertising.

Google API Services User Data Policy

The Studio’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Data is used only to provide the features described above to the channel owner.

Keeping and deleting data

  • The only YouTube data the Studio keeps is the ID of each video it uploaded and which title and thumbnail version is live. Both are about the owner’s own videos. Analytics figures aren’t stored.
  • The owner can disconnect at any time with Disconnect in the Studio, which deletes the stored sign-in token.
  • Access can also be revoked from the Google account at myaccount.google.com/permissions, or through Google’s security settings page. After revoking, the Studio can no longer reach the account.
  • To ask about or request deletion of any data, email clancyrobert420@gmail.com.

This website

This site has no accounts, forms, cookies, analytics or advertising. It’s hosted on GitHub Pages, and GitHub may log visitors’ IP addresses for security, as described in the GitHub Privacy Statement. Fonts load from Google Fonts. If you email us, your message is used only to reply.

Changes
